# Choice image slots

Drop official Choice photography here, named `<slot>.<jpg|webp|avif|png>`. The
matching placeholder on the storefront is replaced automatically at next build.
Nothing in this folder is fabricated; until files exist, labeled placeholders show.

| Slot | Where | Recommended size |
| --- | --- | --- |
| `logo` | Header wordmark (svg/png, transparent) | 480x120 |
| `hero-main` | Home hero, large | 1600x1800 |
| `hero-inset` | Home hero, small overlap | 800x800 |
| `tile-burgers`, `tile-tacos`, `tile-ramen`, `tile-fries`, `tile-drinks` | Home mosaic | 1200x1200 |
| `item-burger`, `item-burrito`, `item-tacos`, `item-ramen` | Today's Menu | 1000x800 |
| `item-loaded-fries`, `item-wrap`, `item-matcha-latte`, `item-thai-tea` | Featured Specials | 1200x1200 |
| `location-dine-in`, `location-stop-by` | Visit | 1600x1000 |
| `visit-hero` | Visit page banner | 2000x900 |
